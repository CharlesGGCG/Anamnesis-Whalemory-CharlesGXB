# 鲸鱼升级计划（2026-11-15 起）

> 一句话：她已经「记得住、看得见、会动」，下一步是**让记忆真的被用上、让她有自己的节奏、再让她能做事**。

## 一、现在她有什么（五个面）

| 面 | 现状 |
|---|---|
| 人格 | `persona.full.md` + 角色系统（小鲸鱼 / 小C），QQ/网页/桌宠共用一套 |
| 记忆 | 记忆卡（叙事）、全量档案、向量记忆、记忆图谱（2371 节点）、外置记忆库（vault，刚建） |
| 情绪 | 孤独感（幂次增长、挂起加速、私聊释放）、上学时段抑制 |
| 入口 | QQ 桥接、whaleweb（三栏 + 房间）、桌宠、Live2D（11 个动作预设）、B站 生物钟 |
| 感知 | 屏幕陪看（30s 截屏 + 视觉）、B站 观看/评论捕获（刚接） |

## 二、今天体检出来的真实缺口

1. **QQ 唤醒里没有记忆卡**——`buildWakePromptV2` 的 `memoryCardLine`/`vectorBlock` 是 11-08 改版后的死代码，只算长度不进 prompt。QQ 端长期记忆目前只靠图谱召回 + 会话状态 + 新 vault。**这是第一优先。**
2. **vault 还是空的**，自动捕获要观察；网页/桌宠、B站 的注入刚随重启生效，还没在真实对话里验证。
3. **B站 捕获只接了"记"，没接"消化"**——看过的视频进了图谱，但她不会第二天主动聊「昨天看的那个」。
4. **观看队列没验证**——队列为空，从没真机走到「0) 待看队列」那一步。
5. **语音只在 L2D/桌宠链路**：QQ 和网页发不出她的声音（voxd 8765 也没起）。
6. **网页/桌宠没有工具**——QQ 端工具很全（B站/搜索/记忆），网页里她只能纯聊天。
7. **主动性靠固定 tick**：现在是每 60s 检查 + 随机间隔，不是"想说话才说话"。

## 三、四个阶段

### P1（1~2 周）记得住、叫得应

| 任务 | 改哪里 | 验收 |
|---|---|---|
| 记忆卡接回 QQ 唤醒 | `src/bridge.js` 的 `base` 数组加 `memoryCardLine` | QQ 里问「记得我昨天说…」能答出来 |
| vault 真正用起来 | 手动种 5~10 条（承诺/生日/雷区）+ 观察自动捕获一周 | `plugin.log` 出现「自动收下 N 条」；命中时 prompt 里有「你记得这些」 |
| 承诺闭环 | vault 加 `dueAt` 到期提醒 + 兑现确认（`vault done`） | 答应的事到点她会提 |
| 记忆卫生 | 每周摘要合并（把 7 天碎记录压成几条）+ 敏感信息脱敏 | 卡增长变慢、`full` 档案可检索 |

### P2（3~4 周）有节奏、会主动

| 任务 | 说明 |
|---|---|
| 生物钟 2.0 | 上学/深夜/周末不同行为；主动开口从"随机间隔"改成"孤独感 + 话题池 + 记忆触发" |
| 她的日常 | 每天自动写一篇自己的日记（her-room 已有工具）、每周回顾一次 |
| 主动关心 | 基于 vault（承诺/生日/考试）和 B站 观看，主动开口；说错了能自我纠正 |
| 语音接入 QQ/网页 | 复用 CosyVoice 或云端 TTS，先做"她主动发语音" |

### P3（1~2 月）能做事

| 任务 | 说明 |
|---|---|
| 直播落地 | 按 `docs/直播方案.md` 走 P1 干跑 → P2 推流 |
| B站 消化 | 看完视频 → 第二天主动聊/写短评；评论回复走记忆 |
| 给她工具 | 网页/桌宠也能查资料、记东西（先只给"搜索 + 记忆"两类，别给 shell） |
| 双人协同 | 小C 和鲸鱼互相记得对方说过什么（客厅已有基础） |

### P4（长期）像一个住在电脑里的人

- **连续性**：跨会话的「今天发生了什么」摘要；睡前/醒来的小仪式。
- **自我模型**：知道自己有哪些记忆、哪些不确定；被问「你记得吗」能诚实说"模糊了"。
- **边界**：公开场（直播/B站）与私密场的记忆隔离继续收紧。

## 四、本周 Top 3（建议直接做）

1. **记忆卡接回 QQ**（`base` 加一行 + 测试）——1 小时，收益最大。
2. **vault 种子 + 自动捕获观察**——你把 5~10 条重要的事发我，我批量入库。
3. **生物钟 2.0 第一版**——时段行为（上学/深夜/周末）+ 话题池，替换纯随机。

## 五、明确不做

- 无人值守 24h 直播（平台判挂机 + 出事没人管）
- 接支付/收款/抽奖
- 在任何公开场泄露主人隐私（住址/学校/作息/密钥）
- 用她的账号做批量刷屏/互关/引流

## 六、风险

| 风险 | 缓解 |
|---|---|
| 记忆越多越容易"记串" | vault 关键词命中 + 卡的模糊标注 + 全量档案可追溯 |
| 主动说话变骚扰 | 时段/频率上限 + 孤独感只在私聊生效 |
| 直播公开暴露 | 四层过滤 + kill switch + 第一版有人在场 |
| 成本 | 每轮 token 预算 + 记忆库只在写入时调 LLM |
