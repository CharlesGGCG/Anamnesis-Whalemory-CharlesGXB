## 二、还要你做的（B站账号侧）

1. **打开哔哩哔哩直播姬**，登录你的 B站账号（`D:\bili\livehime\livehime.exe`）
2. **确认实名/开播权限**：直播姬会提示；没实名就按它的引导做
3. 直播姬里切到 **「第三方推流」/「推流码」**（不同版本叫法不同，在设置或开播页），复制两样东西：
   - 推流地址：形如 `rtmp://live-push.bilivideo.com/live-bvc/`
   - 推流密钥：形如 `?streamname=...&key=...`
4. **OBS → 设置 → 直播**：
   - 服务：**自定义**
   - 服务器：`rtmp://live-push.bilivideo.com/live-bvc/`
   - 串流密钥：粘贴第 3 步的密钥
5. 回到 OBS 主界面点 **「开始直播」**；再在直播姬/网页点「开始直播」让房间进入直播状态（第三方推流模式下以 OBS 推流为准，房间状态按 B站后台）

> 推流密钥是敏感信息：**不要**发到聊天里、不要写进仓库/日志。OBS 自己保存即可。

## 八、B站开播被拒（60045）与虚拟摄像头方案

### 现象

直播姬「推流码推流」→ 点开始直播 → 报：

```text
60045 无法开始推流！您账号在当前IP下未满足开播条件（注册时间>30天 且 粉丝数>500）
```

### 根因

- 直播姬登录的是 **鲸鱼号 `290323755`**（`%LOCALAPPDATA%\bililive\User Data\290323755\`），不是主人的 6 级大号
- 该号 **粉丝 36**（`api.bilibili.com/x/relation/stat`），远低于「推流码推流」要求的 500
- 关键区分：**「推流码推流」= 第三方推流**，B站要求粉丝门槛（2025-05 后第三方权限更收到 5000 粉）；
  而**直播姬普通直播模式**没有这个门槛——朋友 100 粉能播，用的是官方模式

### 可行方案（按推荐顺序）

1. **官方模式 + OBS 虚拟摄像头**（不需要粉丝门槛，鲸鱼号可直接用）
   - OBS →「启动虚拟摄像头」（已启动，当前画面 = 鲸鱼直播场景）
   - 直播姬 → 普通「直播」模式 → 添加素材 → **摄像头** → 选 `OBS Virtual Camera`
   - 再加一个**系统声音**源（鲸鱼 TTS 走系统声音，才能被采集）
   - 点「开始直播」
2. **换主人的 6 级大号**登录直播姬，再用「推流码推流」（需粉丝 ≥500；若主号粉丝够就能过）
3. 想用 OBS 直接推流（画质最好）：账号粉丝需 ≥500（第三方权限 5000），或走国内 IP 中转

### 已验证

- 鲸鱼号粉丝：**36**；直播姬登录 uid：`290323755`
- OBS 虚拟摄像头已启动，输出 1080p60；切换到「鲸鱼直播」集合即鲸鱼画面
